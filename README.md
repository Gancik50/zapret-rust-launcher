# Zapret Rust Launcher

Автоматический лаунчер для **zapret-discord-youtube** с поддержкой игры в **Rust**.

![Demo](demo.gif)

## Проблема

Античит Easy Anti-Cheat (EAC) в Rust блокирует и закрывает процесс winws.exe (Zapret), так как считает его метод перехвата трафика (драйвер WinDivert) уязвимостью или читом.

## Решение

Этот лаунчер:
1. Останавливает и удаляет WinDivert перед запуском
2. Запускает zapret с настроенной конфигурацией

## ВАЖНО

Запускайте **перед** запуском Rust

Нельзя в service.bat выбирать 1. Install Service и если у вас в оригинальном Zapret установлен Install Service то удалите Install Service

Если что не работает попробуйте полазить в настройках Zapret

И кроме github нигде нету.

Не ведитесь на фэйковые тг каналы.

## Установка

1. Скачайте и распакуйте архив
2. Запустите `launch.bat` от имени администратора (или просто дважды кликните — запрос прав произойдёт автоматически)

## Как использовать

1. Запустите `launch.bat`
2. Выберите конфигурацию (пункт [2] или при первом запуске)
3. Нажмите [1] для запуска
4. Откройте Rust и играйте

## Как это работает

```
launch.bat
    │
    ├── sc stop windivert (3 раза)
    ├── sc delete windivert (3 раза)
    └── Запуск general (ALT9).bat из zapret
```

## Автоматическое обновление

При каждом запуске скрипт проверяет последний релиз на GitHub и скачивает его при наличии обновлений.

## Требования

- Windows 10/11
- Права администратора (запрашиваются автоматически)
- Подключение к интернету (для обновлений)

## Примечание

- Для работы zapret требуются драйверы WinDivert
- Если «Запрет» добавлен в автозапуск, уберите его оттуда и перезагрузите компьютер
- Если «Запрет» добавлен в автозапуск, уберите его оттуда и перезагрузите компьютер
